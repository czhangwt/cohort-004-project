# Components

## UI Primitives (`components/ui/`)

shadcn/ui primitives: button, card, input, label, select, skeleton, tabs, textarea.

## Key Components

- **`components/sidebar.tsx`** — Main app sidebar with nav, recent courses, progress bars.
- **`components/dev-ui.tsx`** — Dev-only panel for switching users, setting dev country (PPP testing).
- **`components/monaco-markdown-editor.tsx`** — Monaco-based markdown editor with preview toggle.
- **`components/youtube-player.tsx`** — YouTube embed wrapper with playback event tracking.
- **`components/user-avatar.tsx`** — DiceBear avatar component.
- **`components/course-image.tsx`** — Course cover image with fallback.
