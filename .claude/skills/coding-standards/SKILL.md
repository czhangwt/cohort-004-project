# Coding Standards

This skill routes you to the right reference file for the domain you're working in. **Do NOT load all reference files at once** — read only the one(s) relevant to your current task.

## Index

| Domain | File | When to read |
|--------|------|--------------|
| TypeScript patterns | [typescript.md](typescript.md) | Writing any function, return type, or type annotation |
| Imports | [imports.md](imports.md) | Adding or fixing import statements |
| Database | [database.md](database.md) | Creating/altering schema, writing queries, timestamps, soft deletes |
| Routing | [routing.md](routing.md) | Creating routes, loaders, actions, or error boundaries |
| Forms & Validation | [forms.md](forms.md) | Handling form submissions, validating input |
| Auth | [auth.md](auth.md) | Protecting routes, checking current user |
| Testing | [testing.md](testing.md) | Writing or updating tests |
| Components & UI | [components.md](components.md) | Creating components, styling, Tailwind classes |
| Pricing | [pricing.md](pricing.md) | Storing or displaying prices |

## Usage

When you need a standard (e.g., "how do I store a timestamp?"), read the reference file for that domain. Each file is self-contained — you don't need to cross-reference.
